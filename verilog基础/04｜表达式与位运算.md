# 表达式与位运算

返回 [[00｜Verilog基础·学习地图]] · 前篇 [[03｜数值表示与数据类型]] · 后篇 [[05｜编译指令与宏]]

## 一、按用途区分运算符

| 类别 | 常用运算符 | 结果特点 |
|---|---|---|
| 算术 | `+ - * / % **` | 需要分析位宽、溢出与符号；幂运算的综合支持另行确认 |
| 关系 | `< <= > >=` | 得到 1 位比较结果，未知输入可能使结果为 x |
| 相等 | `== !=` | 四态参与比较时可能为 x |
| 全等 | `=== !==` | 把 x/z 也当作可比较状态，结果只为 0/1 |
| 逻辑 | `! &&`、双竖线逻辑或 | 对操作数整体判断真假，结果 1 位 |
| 按位 | `~ & ^`、竖线按位或、`~^` | 对各位分别计算 |
| 归约 | 一元 `&`、竖线、`^` 及其取反 | 将一个向量归约成 1 位 |
| 移位 | `<< >> <<< >>>` | 位移动、丢弃与补位 |
| 拼接/重复 | `{a,b}`、`{N{a}}` | 拼接位模式，宽度可直接计算 |
| 条件 | `cond ? a : b` | 按条件选择表达式 |

在源代码中，逻辑或写为 `||`，按位/归约或写为 `|`。表格中将竖线用文字表示，以便 Markdown 正常显示。

`<=` 在表达式如 `if (a <= b)` 中是小于等于，在过程语句 `q <= d;` 中是非阻塞赋值，须结合语法位置区分。

## 二、按位、逻辑和归约不能混用

假定 `a=4'b1010`，`b=4'b1100`：

| 表达式 | 结果 | 含义 |
|---|---|---|
| `a & b` | `4'b1000` | 每一位做与运算 |
| `a && b` | `1'b1` | a、b 整体都为非零 |
| `&a` | `1'b0` | a 的所有位是否均为 1 |
| `^a` | `1'b0` | a 中 1 的个数为偶数 |
| `!a` | `1'b0` | a 不是零 |
| `~a` | `4'b0101` | 每一位取反 |

逻辑结果带未知并非总是 x：例如 `0 && x` 可确定为 0；`1 || x` 可确定为 1。分析时看已知信息是否足以决定结果。

## 三、相等与全等

```verilog
// 仅用于仿真理解：
// 1'bx ==  1'bx  -> x
// 1'bx === 1'bx  -> 1
```

自检查 testbench 常用 `!==`：当实际输出包含 x/z 且参考值为确定二进制时，也能可靠判失败。

```verilog
if ({Co, So} !== expected)
    $fatal(1, "adder mismatch");
```

RTL 的普通功能比较通常用 `==`；不要把 `===` 对未知态的仿真判断直接解释成可检测物理未知电平的普通电路。

## 四、拼接与加法位宽

```verilog
wire [7:0] joined = {a4, b4};  // a4 在高 4 位
wire [7:0] repeated = {2{a4}};
wire [4:0] total = {1'b0, A} + {1'b0, B} + {4'b0000, Cin};
```

最后一条假定 A、B 为 4 位、Cin 为 1 位。先扩成 5 位再求和，能清楚表达要保留进位。赋给 4 位目标会丢弃第 5 位。

> [!warning] 不能简单记成“加法结果总比操作数多一位”
> Verilog 表达式宽度受操作数与赋值上下文共同影响；拼接内的子表达式等位置又可能自定宽度。明确扩展输入，比依赖隐含推导更稳妥。

一位全加器可用布尔式，也可用显式扩位的加法式：

```verilog
assign Sum  = A ^ B ^ Cin;
assign Cout = (A & B) | (A & Cin) | (B & Cin);

// 另一种独立实现，不要和上面同时驱动同一输出。
// assign {Cout, Sum} = {1'b0, A} + {1'b0, B} + {1'b0, Cin};
```

对确定的 0/1 输入，功能一致；有 x/z 时，不同表达式传播未知值的方式可能不同。综合结果还需工具实际分析。

## 五、逻辑移位与算术移位

设 `s` 为 `reg signed [7:0]`，位模式是 `1111_0000`（-16）：

| 表达式 | 位模式 | 数值解释 |
|---|---|---|
| `s >> 2` | `0011_1100` | 60 |
| `s >>> 2` | `1111_1100` | 有符号 -4 |
| 无符号同位模式 `u >>> 2` | `0011_1100` | 60 |

`>>>` 只有在左操作数按有符号表达式处理时才复制符号位。必要时使用 `$signed(u) >>> 2`，但它只改变符号解释，不增加位宽。

表中的位模式是将各移位式独立赋给 8 位目标后的观察结果。若把移位式直接放进与无符号常量的比较中，外层表达式的符号规则还可能反过来影响运算。调试时可先把移位结果保存到明确宽度的中间变量，再检查位模式，避免把比较上下文造成的变化误认为移位运算符本身失效。

`<<` 和 `<<<` 在同一固定宽度下都从低位补零，高位移出即丢弃。算术右移对负数的取整方向也要注意：`-3 >>> 1` 得 -2，而整数 `-3 / 2` 向零截断得 -1，不能无条件等同。

## 六、条件表达式与优先级

```verilog
assign y = sel ? p1 : p0;
assign z = a ? b : (c ? d : e);
```

条件明确为真/假时选择相应分支。条件含未知且不能确定真假时，会对两个分支进行逐位合并：相同位可保留，不同位为 x。这与 `if` 把未知条件当成未成立的分支行为不同。

常见优先级从高到低：一元、乘除模、加减、移位、关系、相等、按位、逻辑、条件。不要依赖记忆去读复杂式子，使用括号表达意图：

```verilog
if ((state == IDLE) && ready) begin
    // ...
end
```

拼接和位选取通常得到无符号表达式；signed/unsigned 混算可能使比较按无符号进行。负数比较和移位前，尤其要检查类型。

## 七、复习检查

- 为什么 `>>>` 并不保证补 1？
- 加法要保留进位时，明确扩位在哪里做？
