## 二、最常用的四个模板

以下均为模块内片段，信号需先按说明声明。

**持续组合关系，y 为 wire：**

```verilog
assign y = sel ? b : a;
```

**完整组合过程，y 为 reg：**

```verilog
always @* begin
    y = a;
    if (sel) y = b;
end
```

**异步低有效复位寄存器，q 为 reg：**

```verilog
always @(posedge clk or negedge rst_n) begin
    if (!rst_n) q <= 1'b0;
    else        q <= d;
end
```

**仿真自检查，actual/expected 宽度一致：**

```verilog
if (actual !== expected)
    $fatal(1, "mismatch");
```

## 三、复习自测

> [!question]- 为什么输出声明为 reg 也可能是组合逻辑？
> reg 表示可由过程赋值的变量。若组合敏感过程对所有输入情况完整赋值，不需要保存先前结果，就可描述组合逻辑。

> [!question]- 同一过程里 a<=b、b<=a 能交换旧值吗？
> 在没有其他干扰写入、且两句都在更新前读取右值的基本例子中，可以。若用阻塞赋值，第二句会读取第一句更新后的值。

> [!question]- #5 a=b 与 a=#5 b 写入值为什么可能不同？
> 前者到 5 个时间单位后才读取 b；后者现在读取 b，保存后等待 5 个时间单位再写 a。

> [!question]- 一个 PAD 同时有 0 和 1 驱动，结果一定是 x 吗？
> 相同有效驱动强度的冲突会得到 x；若驱动强度不同，还要按强度解析。force 另有覆盖语义。

> [!question]- parameter 与输入端口的区别是什么？
> parameter 在展开阶段确定实例配置；输入端口传递运行时信号，不能用它任意改变已展开的结构数量和端口宽度。

> [!question]- 当前 Ctrl+Shift+B 为什么可能失败？
> 任务调用的脚本依赖 sim.f，而本次检查时该列表已缺失。恢复列表或改为显式源文件命令后再运行，详见第 01 篇。
