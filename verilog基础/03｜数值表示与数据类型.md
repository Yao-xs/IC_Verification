# 数值表示与数据类型

返回 [[00｜Verilog基础·学习地图]] · 前篇 [[02｜设计方法与语言骨架]] · 后篇 [[04｜表达式与位运算]]

## 一、四态逻辑

| 状态 | 含义 | 常见来源 |
|---|---|---|
| `0` | 逻辑低 | 确定的驱动或变量值 |
| `1` | 逻辑高 | 确定的驱动或变量值 |
| `x` | 未知 | 未初始化、驱动冲突、未知输入传播 |
| `z` | 高阻态 | 该驱动释放线网，未提供 0/1 |

`x` 与 `z` 都不是普通二进制数。`z` 参与多数算术/逻辑运算时通常产生未知效果；同强度的相反线网驱动会解析为 `x`。具体多驱动例子见 [[06｜连续赋值与三态驱动]]。

## 二、定宽常量

```text
位宽 ' [s] 进制 数字
```

| 写法 | 含义 |
|---|---|
| `4'b1010` | 4 位二进制，位模式 1010 |
| `8'hA5` | 8 位十六进制，位模式 1010_0101 |
| `6'o17` | 6 位八进制，十进制 15 |
| `8'd10` | 8 位无符号十进制 10 |
| `8'shF0` | 8 位有符号位模式 F0，按补码解释为 -16 |
| `-8'sd5` | 对有符号 8 位数 5 使用一元负号 |
| `4'b10xz` | 含未知位和高阻位的 4 位常量 |

进制只决定数字如何书写，不决定硬件“采用十进制运算”。下划线用于分组阅读，不占位宽。负号放在常量外，不写成 `8'sd-5`。

普通无尺寸十进制整数（例如 `10`）是有符号、至少 32 位的整数常量。它与小位宽向量混算时会影响表达式宽度与符号；位级电路中尽量明确尺寸和类型。SystemVerilog 的 `'0`、`'1` 是另一类无尺寸无进制填充值，不能与普通整数 `0`、`1` 混为一谈。

## 三、补码、扩展与截断

N 位无符号数范围为 `0` 到 `2^N-1`；N 位有符号补码范围为 `-2^(N-1)` 到 `2^(N-1)-1`。

```verilog
reg        [3:0] u;
reg signed [3:0] s;
reg        [7:0] wide_u;
reg signed [7:0] wide_s;

initial begin
    u = 4'b1111;    // 无符号解释为 15
    s = 4'b1111;    // 有符号解释为 -1
    wide_u = u;     // 零扩展：0000_1111
    wide_s = s;     // 符号扩展：1111_1111
    u = 8'hA5;      // 截掉高位，保留低 4 位：0101
end
```

例子是模块内片段。扩展取决于右侧表达式的类型和上下文，不能把“左边声明 signed”当作所有右侧子表达式都自动有符号的保证。混合 signed/unsigned 时先统一类型，见 [[04｜表达式与位运算]]。

## 四、线网与变量

| 类型 | 语义 | 常见赋值方式 | 未初始化/未驱动时 |
|---|---|---|---|
| `wire` | 由驱动源决定当前解析值的线网 | 模块级 `assign`、端口、门输出 | 普通未驱动 wire 为 z |
| `tri` | 支持多驱动解析的线网，与 wire 语义相同 | 三态总线 | 无驱动时 z |
| `reg` | 保存最近过程赋值结果的四态变量 | `initial/always` 中 `=`、`<=` | 默认 x |
| `integer` | 32 位有符号四态变量 | 循环计数、仿真整数 | 默认 x |
| `time` | 64 位无符号四态变量 | 保存仿真时间 | 默认 x |
| `real` | 实数变量 | 仿真数学计算 | 默认 0.0 |
| `event` | 命名事件的同步对象 | `-> e`、`@(e)` | 不存储数据值 |

> [!important] wire 的“线”应如何理解
> `wire` 表达连接与驱动解析，不靠过程给自己记住一个新值。多个驱动可共同连接线网，但必须分析冲突；变量 `reg` 则通常坚持单一过程负责。

`reg` 并不必然产生触发器：

```verilog
reg y;
always @* y = a & b;  // 完整的组合关系
```

只有结合时钟边沿或保持行为，才谈得上具体存储电路。传统 Verilog 的模块级连续赋值左值使用线网；过程赋值左值使用变量。

**SystemVerilog 补充**：`logic` 是四态数据类型，常用于变量；`wire logic` 仍是线网。`logic` 不是 `wire` 多驱动解析语义的通用替代品。现有 `counter.sv` 使用 `logic` 和 `always_ff`，需要相应语言模式。

## 五、向量、位选取与数组

```verilog
reg [7:0] data;
reg [7:0] mem [0:15];
```

`data` 是一组 8 位；`mem` 是 16 个元素，每个元素 8 位。`data[3]` 取一位，`mem[3]` 取一个 8 位元素。

```verilog
wire [3:0] low = data[3:0];
wire [3:0] high = data[7:4];
```

对 `[7:0]`，左边的索引 7 是高位；也可以声明 `[0:7]`，这时索引 0 对应左端高位。不要把“编号大”机械等同于“高位”，切片方向应与声明一致。

固定片选宽度必须在编译/展开时可确定；`data[hi:lo]` 的两个端点不能随仿真任意变化。Verilog-2001 的索引片选允许起点变化、宽度固定：

```verilog
// 假定 bus 为 [31:0]，base 合法且不越界。
bus[base +: 8]  // 从 base 起，向索引增大方向选 8 位
bus[base -: 8]  // 从 base 起，向索引减小方向选 8 位
```

## 六、复习检查

- `4'b1111` 与 `4'sb1111` 位模式相同，数值解释是否相同？答：15 与 -1。
- `reg` 是否证明硬件存在寄存器？答：不能，需要看过程行为。
- 输入是变量、输出接线网，是否冲突？答：不冲突，分别描述信号在该层的角色。
