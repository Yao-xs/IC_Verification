# 编译指令与宏

返回 [[00｜Verilog基础·学习地图]] · 前篇 [[04｜表达式与位运算]] · 后篇 [[06｜连续赋值与三态驱动]]

## 一、编译指令与普通语句的边界

编译指令以反引号开头，例如 `` `define ``；它不是单引号 `'`。普通语句描述模块和行为，编译指令则影响源文件的处理与编译环境。

| 指令 | 作用 |
|---|---|
| `` `define `` / `` `undef `` | 定义 / 取消文本宏 |
| `` `include `` | 将另一个文件的文本包含进来 |
| `` `ifdef `` / `` `ifndef `` | 按宏是否存在选择代码 |
| `` `elsif `` / `` `else `` / `` `endif `` | 条件编译的后续分支与结束 |
| `` `timescale `` | 设置后续相关模块的时间单位和精度 |
| `` `default_nettype `` | 控制隐式线网类型，可用 none 禁止隐式线网 |
| `` `resetall `` | 将相应编译指令状态恢复默认，不等同于取消所有宏 |

这些指令通常不加普通语句的结尾分号；宏若有意包含分号则会成为替换文本的一部分，需格外谨慎。

## 二、宏定义与引用

```verilog
`define DATA_DW 32
module buffer_example;
    reg [`DATA_DW-1:0] data_in;
endmodule
`undef DATA_DW
```

定义时写名字，**引用时仍需反引号**。`reg [DATA_DW-1:0]` 会尝试使用标识符 DATA_DW，而不是引用宏；除非另有同名参数，否则会出错。

宏是文本处理机制，可能影响后续文件，具体范围受编译单元和工具选项影响。模块位宽的可复用配置优先采用 [[13｜参数化例化与生成结构|parameter]]。

## 三、条件编译与头文件保护

```verilog
// defs.vh 内容示意
`ifndef PROJECT_DEFS_VH
`define PROJECT_DEFS_VH
`define DATA_DW 8
`endif
```

使用时：

```verilog
`include "defs.vh"
```

头文件保护避免同一编译单元重复包含。不要既 `include` 一个完整模块文件，又把同一文件作为编译输入，造成重复定义。

```verilog
// 放在 testbench 模块内部。
`ifdef DEBUG
    initial $display("debug enabled");
`elsif TRACE
    initial $display("trace enabled");
`else
    initial $display("normal mode");
`endif
```

`ifdef DEBUG` 判断宏**是否定义**，不是判断它的数值是否非零。即使定义为 0，它也成立。仿真运行时的 `if` 则检查表达式，两者发生阶段不同。

## 四、时间单位与精度

```verilog
`timescale 1ns/1ps
```

- `#1` 表示等待 1 ns。
- 延时按 1 ps 精度量化，例如 `#0.125` 为 125 ps。
- 若改为 `1ns/1ns`，小数延时会按 1 ns 精度量化，可能被舍入到零。

`timescale` 不生成时钟，也不改变物理电路延时，只规定相关仿真时间数值的解释。多个文件中不一致或遗漏的设置容易受编译顺序影响，因此 TB 与设计的时间设置应明确。

SystemVerilog 还可在模块中声明 `timeunit/timeprecision`，留待后续学习。详见 [[09｜时序控制与事件]]。

## 五、禁止隐式线网

```verilog
`default_nettype none
module and2(input wire a, b, output wire y);
    assign y = a & b;
endmodule
`default_nettype wire
```

禁止隐式线网可帮助尽早发现端口或信号拼写错误。文件末恢复为 wire，可降低对其他源文件的意外影响；它不会修复位宽或接口设计错误。

## 六、从命令行观察预处理

```powershell
iverilog -E -D DEBUG -I include -o expanded.v top.v
```

`-E` 只输出宏与包含处理后的文本，不运行仿真；`expanded.v` 是检查用的过程文件。编译参数见 [[01｜Icarus环境与仿真流程]]。

## 七、复习检查

- 宏 DATA_DW 的使用形式是 `` `DATA_DW ``。
- 宏与 parameter 的区别是文本替换与实例级配置。
- `timescale` 行没有普通结尾分号。
- `ifdef` 检查定义存在性，普通 `if` 检查运行时表达式。
