# 模块端口与例化

返回 [[00｜Verilog基础·学习地图]] · 前篇 [[11｜过程连续赋值与强制驱动]] · 后篇 [[13｜参数化例化与生成结构]]

## 一、模块类型与实例

```verilog
module full_adder1 (
    input  wire A, B, Cin,
    output wire Sum, Cout
);
    assign Sum  = A ^ B ^ Cin;
    assign Cout = (A & B) | (A & Cin) | (B & Cin);
endmodule
```

full_adder1 是模块类型；父模块中写出的每一个实例是一个具体硬件对象。两个实例各自有独立的端口、内部信号和层次位置。

模块例化不等于软件函数调用。例化的硬件持续存在，不是执行流遇到这一行时才临时调用一次。

## 二、端口方向与数据类别

| 声明 | 含义 | 常见用途 |
|---|---|---|
| `input wire a` | 模块读取外部驱动 | 输入数据、时钟 |
| `output wire y` | 模块内由连续/结构驱动 | assign 输出、子模块输出 |
| `output reg q` | 模块内由过程赋值 | 组合过程或时序过程输出 |
| `inout wire pad` | 可读可驱动的双向节点 | 三态 I/O |

端口方向与变量类别是两个维度。父层常用 reg 产生 TB 激励，接到子模块的 input wire；父层用 wire 接收 DUT 的 output reg 也完全正常。

## 三、命名端口连接

```verilog
full_adder1 u_fa (
    .A(a),
    .B(b),
    .Cin(cin),
    .Sum(sum),
    .Cout(cout)
);
```

- full_adder1：模块类型。
- u_fa：父模块内唯一的实例名。
- `.A`：子模块声明的端口名，大小写须一致。
- `(a)`：父模块中提供的实际信号或表达式。

输入端口可以接常量或表达式，例如 `.Cin(1'b0)`；输出端口需要连接可被驱动的对象，不能把普通计算表达式当输出接收目标。

位置连接也合法：`full_adder1 u_fa(a,b,cin,sum,cout);`，但完全依赖声明顺序。学习与工程代码优先使用命名连接，避免增删端口后静默接错。空接 `.unused()` 应是有意省略，并留意工具警告。

## 四、位宽与方向检查

若 4 位端口接了 2 位信号，工具可能扩展、截断或报告警告。不能以“编译未报错”证明接口正确。

双向 PAD 同时被模块内部 assign 和外部 TB 驱动，应是 `inout wire`。历史警告 `input port PAD is coerced to inout` 指向实例连接处，但根因在子模块的端口声明；当前工作区已经修正。

## 五、层次访问使用实例路径

工作区中四位加法器实例名是 FA4：

```verilog
// tb_full_adder4 内的观察片段。
$display("carry chain=%b", FA4.co_temp);
```

从根层次写全路径则是 `tb_full_adder4.FA4.co_temp`。模块类型名 full_adder4 不会自动替代实例名 FA4。

```text
tb_full_adder4
└── FA4 : full_adder4
    ├── FA0 : full_adder1
    ├── gen_adders[1].FA : full_adder1
    ├── gen_adders[2].FA : full_adder1
    └── gen_adders[3].FA : full_adder1
```

例如 `FA4.gen_adders[2].FA.Cout` 可用于观察第 2 位实例的进位输出。这里的 2 是展开后实例索引，不应随意用运行时变量当成普通数组索引访问层次结构。

层次访问适合 TB 观察内部信号；模块之间的正常数据通路优先通过端口连接，以保留可复用性。

## 六、顶层与编译输入

TB 通常是无端口的根模块，内部例化 DUT。即使一个模块未在源码中被其他模块例化，也可以被 `iverilog -s` 选为仿真根；仿真不要求“必须先被别的模块例化”。

源文件列表要包含 DUT 及其依赖，但定义出现的先后一般不等同于仿真顺序；宏、include 和 SV 包等另有编译顺序要求。

## 七、复习检查

- `full_adder1 FA0 (...)` 中哪个是类型，哪个是实例？
- `.Sum(So[0])` 中哪边属于子模块，哪边属于父模块？
- 为什么递归例化 full_adder4 不能自动得到四位进位链？
- 端口位宽、方向、名字是否与子模块声明一致？
