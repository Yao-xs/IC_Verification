# 条件分支与循环

返回 [[00｜Verilog基础·学习地图]] · 前篇 [[09｜时序控制与事件]] · 后篇 [[11｜过程连续赋值与强制驱动]]

## 一、if/else 表达条件与优先级

```verilog
// 模块内组合过程，sout 声明为 reg [1:0]。
always @* begin
    if (sel == 2'b00)
        sout = p0;
    else if (sel == 2'b01)
        sout = p1;
    else if (sel == 2'b10)
        sout = p2;
    else
        sout = p3;
end
```

依次判断，第一个为真的分支执行，其余跳过。条件结果若为 x/z，则不会当作真进入该分支。上例 sel 含未知时也可能最终进入 p3，因此“完整赋值”不等于“已经处理好了无效选择码”。

`else` 与最近的未匹配 if 配对。多层条件建议使用 begin/end，减少缩进与实际语法不一致。

## 二、case 表达离散选择

```verilog
always @* begin
    sout = 2'b00;
    case (sel)
        2'b00: sout = p0;
        2'b01: sout = p1;
        2'b10: sout = p2;
        2'b11: sout = p3;
        default: sout = 2'b00;
    endcase
end
```

普通 case 按四态精确匹配，x/z 不是通配。default 给未匹配情况定义行为；不写 default 并非永远错误，但必须确认所有输出在所有路径已赋值。上例默认 0 是选定策略，可另加 TB 检查暴露未知选择码。

| 结构 | 匹配特点 | 使用边界 |
|---|---|---|
| `case` | 0/1/x/z 精确匹配 | 常规离散选择优先考虑 |
| `casez` | z/问号位作通配 | 可写模式，但需检查意外高阻输入 |
| `casex` | x/z 位都可通配 | 容易掩盖未初始化和错误，RTL 通常避免 |

若多个 case 项可同时匹配，源代码中先匹配的项目生效。功能与综合实现仍需按条件是否互斥分析，不能笼统说“case 一定无优先级、一定更快”。

## 三、for：确定次数的重复

```verilog
integer i;
initial begin
    for (i = 0; i < 4; i = i + 1) begin
        #10 data = i;
    end
end
```

执行次序为初始化 → 条件判断 → 主体 → 步进 → 条件判断。该例是 TB 激励，四次主体在 t=10/20/30/40 执行赋值。

过程 for 若循环边界可静态确定、主体可综合，常会展开成硬件。它不会仅因写了四次循环就自动消耗四个时钟周期；跨周期行为需要时钟、状态或计数控制。

## 四、其他循环

| 结构 | 语义 | 典型用途 |
|---|---|---|
| `repeat(N)` | 进入时计算次数，重复 N 次 | TB 发送固定数量激励 |
| `while(expr)` | 每次进入主体前检查条件 | TB 等待或不定次处理 |
| `forever` | 无限重复 | TB 时钟与持续激励 |

```verilog
// initial 内片段。
repeat (3) @(posedge clk);
while (!done) @(posedge clk);
forever #5 clk = ~clk;
```

forever 后的语句通常不可达，除非用其他机制终止该循环。while 中若条件一直不成立且主体没有等待，仿真可能卡在同一时刻。repeat 的次数不是每轮自动重新读取。

## 五、过程循环与 generate 循环

- initial/always 内的 for 在仿真执行过程中重复语句。
- generate for 在展开阶段创建模块、连线或其他结构。
- 前者常用 integer，后者使用 genvar。
- 即使两者最终都可能得到重复硬件，它们的语言阶段与作用域也不同。

四位加法器的生成结构见 [[13｜参数化例化与生成结构]]。

## 六、分号与循环边界

```verilog
// 错误意图示意：if (valid); y = d;
// if 实际控制的是空语句，y = d 会继续执行。
```

循环中多余的分号也会让主体变成空语句。索引从 0 开始且需要 4 个对象时，通常取 `0 <= i < 4`；已有加法器的第 0 位单列，因此生成部分应是 `1 <= i < 4`。

## 七、复习检查

- 组合逻辑未命中分支时，输出是否仍然被赋值？
- sel 含 x 时，if 链与 case 的默认行为是什么？
- for 内没有事件等待，为什么不能认为循环次数等于时钟数？
- 四位加法器的第 3 位是否真的生成且有驱动？
